## Welcome! 👋

Welcome to this responsive QR Code Generator.

## Features

- Enter any URL and generate a QR code instantly.
- Download the generated QR code as a PNG image.
- Copy the QR code image URL directly to your clipboard.
- Responsive and easy-to-use interface.

## How to Use

1- Enter a URL in the input field.
2- Click the QR code button to generate the QR code.
3- Use the Download button to save the QR code image.
4- Use the Share button to copy the QR code image URL to your clipboard.

## Technologies Used

- HTML, CSS, JavaScript
- QRCode.js for generating QR codes
